# Remote Support — unpublished draft

This release has not been published. The Windows helper runs from an administrator PowerShell or a SYSTEM command shell. Sessions require separately issued, short-lived credentials; the release includes none.

## Installation

The command below pins the published 0.1.5 release URL and SHA-256; do not substitute a different download or fingerprint. Paste the complete line into an administrator PowerShell window (Windows PowerShell 5.1 or PowerShell 7) or a SYSTEM command shell. It stages the download in an administrator-and-SYSTEM-only folder, checks the fingerprint before running the installer, and then removes the download folder. On failure it exits that shell with a nonzero status.

```powershell
& { $ErrorActionPreference = 'Stop'; $url = [uri]'https://github.com/shreeve1/remote-support/releases/download/v0.1.5/remote-support-0.1.5.zip'; $sha = '0bda8d76d4f297bbcf02d627c0f38d3059f158bf4f39f89c615db1934a7d09d3'; $id = [Security.Principal.WindowsIdentity]::GetCurrent(); if (-not ($id.IsSystem -or ([Security.Principal.WindowsPrincipal]$id).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator))) { [Console]::Error.WriteLine('Run this command in an administrator PowerShell or as SYSTEM.'); exit 1 }; $owned = $false; $client = $null; $stream = $null; $tls = $null; $failed = $false; try { if ($url.Scheme -ne 'https' -or $sha -notmatch '^[0-9a-f]{64}$') { throw 'Use an HTTPS release URL and a trusted 64-character SHA-256 fingerprint.' }; $legacy = $PSVersionTable.PSVersion.Major -lt 6; if ($legacy) { $tls = [Net.ServicePointManager]::SecurityProtocol; $protocols = $tls -bor [Net.SecurityProtocolType]::Tls12; if ([Enum]::IsDefined([Net.SecurityProtocolType], 'Tls13')) { $protocols = $protocols -bor [Net.SecurityProtocolType]::Tls13 }; [Net.ServicePointManager]::SecurityProtocol = $protocols; }; $temp = Join-Path $env:windir 'Temp'; if (([IO.File]::GetAttributes($temp) -band [IO.FileAttributes]::ReparsePoint) -ne 0) { throw 'Machine Temp is a reparse point.' }; $dir = Join-Path $temp ('remote-support-download-' + [guid]::NewGuid().ToString('N')); $asm = [Reflection.Emit.AssemblyBuilder]::DefineDynamicAssembly([Reflection.AssemblyName]::new('RemoteSupportBootstrap'), [Reflection.Emit.AssemblyBuilderAccess]::Run); $type = $asm.DefineDynamicModule('Native').DefineType('Native'); $method = $type.DefinePInvokeMethod('CreateDirectoryW', 'kernel32.dll', [Reflection.MethodAttributes]'Public,Static,PinvokeImpl', [Reflection.CallingConventions]::Standard, [int], [type[]]@([string], [IntPtr]), [Runtime.InteropServices.CallingConvention]::Winapi, [Runtime.InteropServices.CharSet]::Unicode); $method.SetImplementationFlags([Reflection.MethodImplAttributes]::PreserveSig); $native = $type.CreateType(); $sd = [Security.AccessControl.RawSecurityDescriptor]::new('O:BAG:BAD:P(A;OICI;FA;;;BA)(A;OICI;FA;;;SY)'); $bytes = [byte[]]::new($sd.BinaryLength); $sd.GetBinaryForm($bytes, 0); $pin = [Runtime.InteropServices.GCHandle]::Alloc($bytes, [Runtime.InteropServices.GCHandleType]::Pinned); $attributes = [IntPtr]::Zero; try { $ptrSize = [IntPtr]::Size; $attributes = [Runtime.InteropServices.Marshal]::AllocHGlobal(3 * $ptrSize); [Runtime.InteropServices.Marshal]::WriteIntPtr($attributes, 0, [IntPtr](3 * $ptrSize)); [Runtime.InteropServices.Marshal]::WriteIntPtr($attributes, $ptrSize, $pin.AddrOfPinnedObject()); [Runtime.InteropServices.Marshal]::WriteIntPtr($attributes, 2 * $ptrSize, [IntPtr]::Zero); if (-not $native::CreateDirectoryW($dir, $attributes)) { throw 'Cannot create protected download folder (it may already exist).'; }; $owned = $true; } finally { [Runtime.InteropServices.Marshal]::FreeHGlobal($attributes); $pin.Free() }; Add-Type -AssemblyName System.Net.Http, System.IO.Compression, System.IO.Compression.FileSystem; $handler = [Net.Http.HttpClientHandler]::new(); $handler.AllowAutoRedirect = $false; $client = [Net.Http.HttpClient]::new($handler); for ($i = 0; ; $i++) { if ($i -gt 5 -or $url.Scheme -ne 'https') { throw 'Unsafe release redirect.' }; $response = $client.GetAsync($url, [Net.Http.HttpCompletionOption]::ResponseHeadersRead).GetAwaiter().GetResult(); try { if ([int]$response.StatusCode -in @(301,302,303,307,308)) { $url = [uri]::new($url, $response.Headers.Location); continue }; $null = $response.EnsureSuccessStatusCode(); $archive = Join-Path $dir 'release.zip'; $file = [IO.File]::Open($archive, [IO.FileMode]::CreateNew, [IO.FileAccess]::Write, [IO.FileShare]::None); try { $response.Content.CopyToAsync($file).GetAwaiter().GetResult() } finally { $file.Dispose() }; break; } finally { $response.Dispose() }; }; $stream = [IO.File]::Open($archive, [IO.FileMode]::Open, [IO.FileAccess]::Read, [IO.FileShare]::Read); if ((Get-FileHash -InputStream $stream -Algorithm SHA256).Hash -ne $sha) { throw 'Hash mismatch; nothing installed.' }; $stream.Position = 0; $zip = [IO.Compression.ZipArchive]::new($stream, [IO.Compression.ZipArchiveMode]::Read, $true); try { foreach ($name in @('Install-RemoteSupport.ps1', 'Protected-Stage.ps1')) { $entry = $zip.GetEntry($name); if ($null -eq $entry) { throw ('Verified ZIP is missing ' + $name + '.'); }; [IO.Compression.ZipFileExtensions]::ExtractToFile($entry, (Join-Path $dir $name), $false); }; } finally { $zip.Dispose() }; $shell = if ($legacy) { 'powershell.exe' } else { 'pwsh.exe' }; & (Join-Path $PSHOME $shell) -NoProfile -NonInteractive -ExecutionPolicy Bypass -File (Join-Path $dir 'Install-RemoteSupport.ps1') -Archive $archive -Sha256 $sha; if ($LASTEXITCODE -ne 0) { throw 'Remote Support installation failed.' }; } catch { [Console]::Error.WriteLine($_.Exception.Message); $failed = $true } finally { if ($null -ne $stream) { $stream.Dispose() }; if ($null -ne $client) { $client.Dispose() }; if ($owned) { try { [IO.Directory]::Delete($dir, $true) } catch { [Console]::Error.WriteLine('Could not remove download folder: ' + $dir); $failed = $true }; }; if ($null -ne $tls) { [Net.ServicePointManager]::SecurityProtocol = $tls }; }; if ($failed) { exit 1 }; }
```

## Trust boundary

A SHA-256 fingerprint in an install command proves only that the downloaded archive matches the fingerprint in that command. Obtain the complete command from a trusted source, such as this repository's verified README or James's own trusted notes. A fingerprint taken from the same unverified page as a download does not establish that either is authentic. Releases are unsigned.
